# Smart Meter Desktop System

نظام مكتبي لإدارة عمليات الكهرباء مبني باستخدام  
**C# (.NET) + WebView2 + HTML/CSS/JavaScript + MySQL**

يهدف المشروع إلى توفير منصة إدارية متكاملة لإدارة المستخدمين، العدادات، القراءات، والفواتير، مع دعم العمل دون اتصال بالإنترنت والمزامنة عند توفره.

---

## 🎯 هدف المرحلة الحالية

هذه النسخة تمثل **المرحلة الأولى (Foundation Phase)** من المشروع، وتركّز على:

- بناء هيكل المشروع بشكل احترافي ومنظم
- تهيئة WebView2 بشكل صحيح
- دعم تحميل واجهات الويب (HTML/CSS/JS) داخل تطبيق C#
- حل مشاكل CORS الخاصة بتحميل الملفات المحلية
- تجهيز نظام تسجيل الدخول كنقطة دخول موحدة للتطبيق

---

## ✅ ما تم إنجازه

### 1. البنية التقنية
- تطبيق مكتبي باستخدام **Windows Forms + WebView2**
- واجهات المستخدم مبنية بالكامل باستخدام:
  - HTML
  - CSS (Tailwind CSS)
  - JavaScript
- ربط الواجهات مع التطبيق عبر `window.chrome.webview.postMessage`

### 2. حل مشكلة CORS (مهم جداً)
- تم استخدام:
  ```csharp
  SetVirtualHostNameToFolderMapping
````

* تشغيل الواجهات عبر:

  ```
  https://app.local/
  ```

  بدلاً من `file://`
* هذا مكّن من:

  * استخدام `fetch()` لتحميل partials
  * تحميل `header.html` و `sidebar.html` بنجاح
  * تشغيل `common.js` بدون قيود أمان

### 3. الواجهات المشتركة (Frontend)

* إنشاء ملف `common.js` مسؤول عن:

  * تحميل الهيدر والسايدبار من مجلد `partials`
  * تفعيل القائمة الجانبية
  * إدارة التبويبات (Tabs) مع دعم تعدد المجموعات
  * تحديث التاريخ
  * القوائم المنسدلة والبحث
* عدم تكرار أي كود واجهات بين الصفحات

### 4. تسجيل الدخول

* واجهة تسجيل دخول جاهزة (HTML/CSS)
* إرسال بيانات الدخول من JavaScript إلى C#
* التحقق من المستخدم عبر `AuthService`
* التعامل مع:

  * نجاح تسجيل الدخول → الانتقال للوحة التحكم
  * فشل تسجيل الدخول → إظهار رسالة خطأ داخل الواجهة
